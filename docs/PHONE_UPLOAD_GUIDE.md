# 📱 How to Upload Wallpapers from Your Phone - Beginner's Guide

## The Easy Way (No Server Setup Needed!)

### Step 1: Open the App on Your Phone
1. Go to the website where AniWalls is hosted
2. Bookmark it for quick access
3. Add to home screen (optional):
   - iOS: Tap Share → Add to Home Screen
   - Android: Tap ⋮ → Install app

### Step 2: Unlock Admin Mode
1. Look at the top-right corner of the app
2. **Tap the crown icon (👑) exactly 3 times quickly**
   - First tap: Nothing happens
   - Second tap: Nothing happens
   - Third tap: Admin login appears! ✨

### Step 3: Enter the Secret Code
1. A popup appears asking for a "secret passcode"
2. Type: `15081983`
3. Tap "Unlock" button
4. You're now in Admin Panel! 👑

## Adding Your Wallpaper

### Step 4: Upload Your Image

You have two options:

#### Option A: Upload from Photos (Recommended)
1. Tap **"Choose image from device"**
2. Allow the app to access your photos
3. Select a wallpaper from your camera roll
4. Wait for preview to load (you'll see a checkmark ✅)

#### Option B: Use URL
1. If you have a direct link to an image
2. Paste it in the **"Image URL"** field
3. Make sure it starts with `https://`

### Step 5: Fill in the Details

**English Title** (Required)
- Example: `Goku Ultra Instinct`
- This is how English speakers see it

**Arabic Title** (Recommended)
- Example: `غوكو - الغريزة الفائقة`
- Users on Arabic mode will see this
- Can use Google Translate if needed

**Anime / Series** (Required)
- Example: `Dragon Ball`, `One Piece`, `Naruto`
- Which anime is this from?

**Category** (Required)
- Select the best match:
  - 🍥 Naruto
  - 🏴‍☠️ One Piece
  - ⚔️ Demon Slayer
  - 🌀 Jujutsu Kaisen
  - 🛡️ Attack on Titan
  - 🐉 Dragon Ball

**Resolution** (Required)
- Choose the image quality:
  - 1080 x 1920 (Full HD)
  - 1440 x 2560 (2K)
  - 2160 x 3840 (4K Ultra HD)

**Style Tag** (Required)
- Pick the main style:
  - 🔥 Neon - Bright, glowing effects
  - 🖼️ Portrait - Character close-up
  - ⚡ Action - Fighting, dynamic scenes
  - 🌙 Dark - Dark, moody vibes
  - 🌿 Nature - Scenery, landscapes

### Step 6: Publish!

1. Tap the **⚡ Publish Wallpaper** button
2. See the success message 🎉
3. Done! Your wallpaper is now live for everyone!

## ❓ Frequently Asked Questions

### Q: I can't find the crown icon
**A:** It's in the very top-right corner of the app, next to the language button. Tap it 3 times quickly.

### Q: The admin panel won't open
**A:** Make sure you:
- Tap it 3 times within 1.6 seconds (not too slow)
- Refresh the page and try again
- Try on a fresh browser tab

### Q: What if I get "Wrong passcode"?
**A:** Check you typed: `15081983` (it's 8 digits)

### Q: The image won't upload
**A:** Try:
- Using a smaller image file
- Switching to "Upload a file" instead of URL
- Checking internet connection
- Clearing browser cache (Settings → Clear Cache)

### Q: Can I edit a wallpaper after uploading?
**A:** Not yet - you can delete it and re-upload it

### Q: How long does it take to appear?
**A:** Instantly! Refresh the app and you'll see it

### Q: Can other people delete my wallpapers?
**A:** No - only you (with admin access) can delete them

### Q: I forgot the passcode
**A:** The admin needs to change it in the app code

### Q: Can I upload from computer instead?
**A:** Yes! Open the app in a web browser on your computer and follow the same steps

## 🎯 Tips for Best Results

### Image Quality
- **Use high-quality images** (2160 x 3840 or higher)
- Aspect ratio should be portrait (tall, not wide)
- Avoid blurry or low-res images

### Titles
- Keep them short and catchy
- Use character/anime names
- Be specific: "Goku Ultra Instinct" is better than "Cool Wallpaper"

### Categories & Tags
- Choose the most accurate category
- Pick tags that match the image style
- Mix of tags helps with search

### Anime Names
- Use the official English name
- Example: "One Piece" not "OP"
- "Jujutsu Kaisen" not "JJK"
