## 🎨 Customize (Optional)

### **Change Admin Password**
1. Open `public/index.html` with a text editor
2. Find: `const ADMIN_PASS='15081983';`
3. Change to: `const ADMIN_PASS='YOUR_SECRET_CODE';`
4. Save and reload

### **Change App Colors**
1. Open `public/index.html` in text editor
2. Find: `:root{color-scheme:dark; --bg:#070710;...}`
3. Modify the hex colors (e.g., `#070710` to `#000000`)
4. Save and reload

### **Add More Wallpapers**
1. Upload via Admin Panel (easiest!)
2. Or edit the `SEED` array in the HTML

## 🆘 Troubleshooting

### **Admin panel won't open**
- Tap crown 👑 **exactly 3 times** (not slower!)
- Refresh the page and try again
- Try a different browser

### **Upload button doesn't work**
- Check the passcode (should be `15081983`)
- Try with a smaller image file
- Check internet connection
- Clear browser cache (Ctrl+Shift+Delete)

### **Wallpapers not showing**
- Wait 30 seconds
- Refresh the page (F5)
- Try in incognito/private mode

### **App feels slow**
- Clear browser cache
- Close other browser tabs
- Try a different browser
- Reduce image file sizes
